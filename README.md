# PlayLabs — PolyQuest: The Secret World of Materials

> An interactive children's science adventure, illustrated storybook, and virtual laboratory for exploring materials science (Grade 8 NCERT curriculum).

---

## 🌟 Features

- **Hands-On Science Exploration**: 
  - 🌱 **Origins**: Discover what materials are and sort natural vs synthetic materials.
  - 🧵 **Meet the Fabrics**: Explore Cotton, Nylon, Polyester, and Acrylic superpowers.
  - 🔬 **Stress & Strength Tests**: Nylon tensile strength vs steel wire + Polyester clothing shop.
  - 🔥 **Fire & Sweat Safety**: Virtual flame test showing synthetic melting + summer sweat absorption.
  - ⚡ **Plastic & Power**: Electrical insulation wire-wrapping + Heat insulation kettle handle test.
  - 🌍 **100-Year Underground Time Journey**: Visual biodegradation simulation of plastics in soil.
  - 🔧 **Synthetic Rubber & Glue**: Stretching polymers & adhesive repair lab.
  - 🏕️ **Pip's Safe Camp Challenge**: Higher-order thinking problem-solving challenge.
  - 📖 **My Discovery Book**: Collected material specimens with science exam terms.
  - 👨‍👩‍👧 **Parent Dashboard**: Real-time diagnostic insights & 5-minute offline home activities.

- **Audio & Voice System**:
  - 🎵 **Joyful Background Music**: Web Audio API synthesized marimba & celesta melodies for kids.
  - 🗣️ **Natural Text-To-Speech (TTS)**: Pip speaks every dialogue and explanation using neural/natural browser speech synthesis.
  - 🎙️ **Voice Magic Unlock (Speech Recognition)**: Kids speak magic science words (like *"NATURAL"*, *"NYLON"*, *"INSULATOR"*) into their microphone to unlock missions!
  - 🎛️ **Audio Toolbar**: Instant toggles for Music, Voice, and Replay.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router with Turbopack)
- **UI & Animation**: React 19, Tailwind CSS 4, Framer Motion 13
- **Audio & Speech**: Web Audio API, Web Speech Synthesis API, Web Speech Recognition API
- **Icons**: Lucide React
